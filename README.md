# وصّلني - V1
نسخة أولية لتطبيق طلب وتوصيل مستقل. تعمل حالياً على المتصفح باستخدام localStorage فقط.

## رفع GitHub Pages
1. أنشئ Repository جديد واجعله Public.
2. ارفع كل الملفات كما هي.
3. تأكد أن `index.html` موجود في الجذر.
4. Settings > Pages > Deploy from a branch > main > /(root) > Save.
5. افتح الرابط الذي يعطيك GitHub.

Backend + قاعدة بيانات + حسابات + لوحة مطعم + لوحة مندوب + إدارة + إشعارات + خرائط + دفع إلكتروني حقيقي.
